Báo Cáo Phân Tích Dự Án GiaoLy

Hệ sinh thái phần mềm quản lý mục vụ hiện đại cho Giáo Xứ

1. Tổng Quan Dự Án

GiaoLy là một hệ sinh thái phần mềm được thiết kế đặc thù cho mô hình Sứ Đoàn Thiếu Nhi Thánh Thể. Dự án số hóa danh sách đoàn sinh, quản lý học vụ, phát hành chứng từ số, và quản lý nhân sự (Giáo Lý Viên, Ban Điều Hành) một cách toàn diện. Kiến trúc hệ thống được chia làm nhiều tầng (N-Tier Architecture) bao gồm API, Application và Domain, cùng với ứng dụng Web độc lập (Frontend).

2. Công Nghệ & Thư Viện Sử Dụng (Tech Stack)

Backend (API & Domain)

  • Ngôn ngữ & Nền tảng: C# và ASP.NET Core 10.0
  • Kiến trúc: Clean Architecture (Tách biệt Domain, Application, API)
  • Cơ sở dữ liệu & ORM: Entity Framework Core 10.0 kết hợp với SQL Server
  • Bảo mật & Phân quyền: Microsoft.AspNetCore.Authentication.JwtBearer (JWT Authentication), BCrypt.Net-Next (Mã hóa mật khẩu)
  • Tài liệu API: Swashbuckle.AspNetCore (Swagger / OpenAPI)
  • Tiện ích khác: ClosedXML (Xử lý file Excel), HtmlSanitizer (Làm sạch nội dung HTML)

Frontend (Web App)

  • Framework chính: Nuxt (v4.4.5) / Vue 3 (Composition API)
  • Giao diện (UI/UX): Nuxt UI (v4.7.1) và Tailwind CSS (v4.3.0) hỗ trợ Light/Dark mode
  • Quản lý trạng thái: Pinia (v3.0.4) và @pinia/nuxt
  • Tiện ích Composable: @vueuse/core
  • Bảo vệ nội dung: isomorphic-dompurify
  • Xử lý dữ liệu Excel: thư viện xlsx
  • Icon: @iconify-json/lucide, @iconify-json/simple-icons

3. Cấu Trúc Cơ Sở Dữ Liệu & Phân Hệ

3.1. Quản Trị & Phân Quyền (Auth & Access Control)

Quản lý người dùng trong hệ thống qua bảng Users. Hệ thống phân cấp 4 nhóm quyền rõ ràng: Admin (Quản trị viên), Secretary (Thư ký), Moderator (Trưởng Ngành), và Viewer (Người xem).

3.2. Học Vụ & Đoàn Sinh (Academic & Students)

Quản lý xuyên suốt từ lý lịch cá nhân (bảng Students), phân lớp học (ClassRooms, AcademicYears, Enrollments) đến bảng điểm điện tử (Grades). Nổi bật là tính năng tự động tính Điểm trung bình (GPA) và Tỷ lệ chuyên cần để xét điều kiện lên lớp một cách tự động.

3.3. Ban Điều Hành (Leadership)

Sử dụng bảng Leaders lưu trữ sơ đồ tổ chức Sứ Đoàn theo 3 cấp độ (Tuyên Úy, Ban Quản Trị, Trưởng Ngành). Dữ liệu này dùng để tự động vẽ sơ đồ tổ chức (Organization Chart) trực quan trên ứng dụng Web.

3.4. CMS & Truyền Thông

Cung cấp khả năng đăng tải thông báo (Announcements) và quản lý tài liệu, văn thư trong một hệ thống thư viện điện tử (Documents).

3.5. Chứng Từ Số (E-Certificates)

Hệ thống cấp phát chứng chỉ số cho các Bí Tích (Rửa Tội, Rước Lễ, Thêm Sức) được lưu qua bảng Certificates. Tính năng tạo ra mã xác thực duy nhất làm tiền đề cho việc quét QR Code xác minh.

4. Tính Năng & Điểm Nhấn Kiến Trúc

  • Trải nghiệm UI/UX Premium: Giao diện tích hợp Glass-morphism, các tông màu gradient nhẹ nhàng (pastel pink/rose, amber), có hỗ trợ chuyển đổi giao diện Sáng/Tối.
  • Song ngữ (I18n): Hệ thống frontend được trang bị đa ngôn ngữ Anh-Việt, có thể dễ dàng chuyển đổi nhanh chóng ở bất kỳ đâu.
  • Thao tác mượt mà: Bảng tính dữ liệu (Data Table) áp dụng công nghệ TanStack của Nuxt UI v3.
  • Bảo Mật Route Chặt Chẽ: Middlewares kiểm tra xác thực và phân quyền (auth.global.ts) bảo vệ ứng dụng ở mọi màn hình.
  • Database Auto-seed: Tự động bổ sung các tài khoản mặc định và dữ liệu hệ thống cần thiết khi ứng dụng khởi chạy nếu cơ sở dữ liệu trống.
